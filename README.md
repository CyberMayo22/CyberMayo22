### 🕵️‍♂️ About Me

I'm a **Digital Forensics Analyst** currently building my skills through the **ICDFA (International Cybersecurity and Digital Forensics Academy) program**, with hands-on focus on:

- 🧬 **Digital Forensics** — evidence acquisition, file carving, steganography analysis, and hash-based integrity verification
- 🛡️ **Web Application Security** — identifying and analyzing vulnerabilities in web applications
- 🐧 **Linux & Shell Scripting** — command-line proficiency for forensic and security workflows
- 📊 **Data Science** — applying analytical thinking to security and forensic datasets

I approach every investigation with the same discipline a real case demands: preserve integrity, document everything, and let the evidence speak.
